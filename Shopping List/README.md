# Shopping List Program

This is a simple C++ program that lets the user create a shopping list.

The user can type as many shopping items as they want. When they are finished, they type `done`, and the program displays the full shopping list.

## What This Program Does

- Welcomes the user
- Asks the user to enter shopping list items
- Stores each item inside a vector
- Keeps asking for items until the user types `done`
- Displays the final shopping list

## Concepts Practiced

This project practices basic C++ concepts such as:

- Vectors
- Strings
- While loops
- For loops
- User input
- Displaying output
- Using `getline()`
