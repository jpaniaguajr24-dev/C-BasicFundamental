# Temperature Converter

This is a simple C++ program that converts Fahrenheit temperatures to Celsius.

The program asks the user to enter 7 Fahrenheit temperatures. It stores those temperatures inside an array, converts each one to Celsius, and then displays the results in a table.

## What This Program Does

- Asks the user to enter 7 Fahrenheit temperatures
- Stores the temperatures in a C++ array
- Converts each Fahrenheit temperature to Celsius
- Displays the Fahrenheit and Celsius temperatures side by side

## Formula Used

Celsius = (Fahrenheit - 32) * 5 / 9
